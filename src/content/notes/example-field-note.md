This file is placeholder text and says nothing about anyone. It exists so the
notes collection has a shape to copy, and so the listing and detail templates
have something to render before real writing arrives.

A note is short. It has one idea, and the idea is usually something learned
while building rather than a conclusion about the world. The frontmatter above
carries only what the list row needs: a title, a date, an optional description,
tags, an optional series, an optional free-form status label. Everything else
belongs in the body.

Headings are optional here. Long notes benefit from two or three `##` sections;
short ones read better as a handful of paragraphs with nothing above them. When
a note grew out of a project, set `relatedBuild` so the two pages link to each
other instead of repeating one another.
